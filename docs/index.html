为什么用它

从单灯玩具到多灯管理器，v1.5 之后已经能覆盖绝大多数桌面照明场景。

💡

多灯并行控制

一个实例管理任意数量的米家 / Yeelight 灯，共享托盘图标、弹窗和快捷键路由，每盏独立配置。

🔒

纯本地通信

基于 python-miio 直连设备的局域网协议，不经过云端。Token 只写入本地配置。

⚡

全局快捷键

每盏灯独立的亮度 / 色温加减快捷键。基于 Windows RegisterHotKey，全屏游戏中也响应。

🌙

系统事件联动

逐灯配置：软件启停、显示器休眠 / 唤醒、系统休眠 / 唤醒时自动开关，组合自由。

🎨

Fluent Design

DWM 原生圆角、半透明、Win11 深色配色。托盘弹窗高度按内容自适应。

☁️

云端一键导入

扫码登录小米账号后可勾选多盏设备批量添加，IP / Token / 型号全自动填入。

📦

免安装单文件

提供打包好的单文件 EXE，双击即用，无需 Python 环境或 pip 依赖。

🔄

IP 变化自动发现

DHCP 续约导致 IP 变化时，程序通过 device_id 在局域网内自动重新定位。

🔔

自动更新检测

启动时自动检查 GitHub Release 新版本，托盘菜单提示，一键跳转下载。

四步跑起来

总用时不到两分钟。

1

下载 EXE

从 最新 Release 页面拿到 MiMonitorLightTray.exe，放到任何你喜欢的位置。

2

双击运行

首次启动会自动弹出设备列表向导。点击 云端导入，扫码登录小米账号。

3

勾选设备

在设备列表中勾选你想控制的灯，点击 确认导入。IP / Token / 型号全自动填入。

4

开始使用

左键单击托盘图标弹出滑杆。想要更精细的每设备控制？点击 ⚙ 打开设置，逐灯配置快捷键与电源策略。

兼容广泛

协议映射从 miot-spec.com 抓取并内嵌，几乎所有能连米家的灯具都能识别。

协议自动切换

程序按设备 model 自动选择 legacy 或 MIoT 协议，未收录的新机型可在设备编辑器里手动启用 MIoT 实验模式尝试。 详见 兼容设备清单。
